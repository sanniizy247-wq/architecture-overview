# Northbridge University Management System

A modern Flask-based university web application with a clean public homepage and structured navigation for future student, staff and administrator features.

## Features included
- Public university homepage
- Student, staff and administrator login portals
- Responsive navigation and dashboard layout
- Admissions, announcements, faculty and contact pages
- Sample university data and demonstration content

## Project structure
- `app.py` - Flask application and route definitions
- `templates/` - HTML pages for all views
- `static/css/styles.css` - custom university branding and responsive styling
- `static/js/app.js` - mobile navigation and small interactive enhancements

## Run locally
1. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the app:
   ```bash
   python app.py
   ```
4. Open the browser at:
   ```bash
   http://127.0.0.1:5000
   ```

## Notes
This is the initial stage of the University Management System, designed to be expanded with student registration, attendance, payments, course management, library services and examinations.
